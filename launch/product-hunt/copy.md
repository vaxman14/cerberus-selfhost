## First maker comment

I built Cerberus because website-security checks are usually scattered across
online graders, heavyweight pentest suites, and command-line tools that do not
leave you with one useful history.

Cerberus puts four heads in one local app: passive surface checks, DNS/email
recon, Lighthouse, and explicitly authorized Nuclei/ZAP/sqlmap testing. It has
local users, stoppable scans, reports you can save as PDF, and optional AI
analysis of saved findings. Your database and encrypted provider credentials
stay on your Docker host.

The public release defaults to passive scans and localhost access. Active tools
require an operator opt-in plus authorization and production-risk confirmation
for each run. It is free software under AGPL-3.0.

I would especially value feedback on installation, false positives, and which
report details help you fix a site fastest.
