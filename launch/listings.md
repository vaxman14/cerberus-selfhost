# Launch listings

## Short description

Cerberus is a free, self-hosted website security and quality scanner combining
passive checks, local Lighthouse, authorized Nuclei/ZAP/sqlmap testing, local
users, run history, PDF-ready reports, and optional AI analysis.

## Docker Hub

**Overview:** Four-headed website security scanner with safe passive defaults.
Run `./scripts/setup.sh`, create a local owner, and keep scan history on your
Docker host. Multi-architecture images support amd64 and arm64.

**Images:**

- `romanvaxman/cerberus-selfhost:0.2.0`
- `romanvaxman/cerberus-tools:0.2.0`
- `romanvaxman/cerberus-aio:0.2.0` (Unraid convenience launcher; Docker socket required)

## Community posts

**Title:** I built Cerberus: a free self-hosted website scanner with Lighthouse, ZAP, Nuclei, and sqlmap

**Body:**

Cerberus combines passive website checks, DNS/email policy checks, local
Lighthouse, and explicitly authorized active testing in one Docker app. It has
local authentication, site/run history, stoppable jobs, PDF-ready reports, and
optional AI analysis. Active scans and remote exposure are off by default.

Repository: https://github.com/vaxman14/cerberus-selfhost

Website: https://cerberusscan.com

Feedback on installation and false positives is welcome. Please only scan
targets you own or are authorized to assess.
