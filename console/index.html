Local credentials never leave this Cerberus installation.

Forgot password?

Passwords are securely hashed and cannot be displayed. Resetting the owner password revokes browser sessions but preserves users, scans, settings, provider profiles, and reports. Replace OWNER_USERNAME with the local owner name.

Docker Hub AIO install

docker exec -it cerberus-aio-cerberus-1 python -m cerberus.userctl reset-password --username OWNER_USERNAME

Standard Docker Compose install

docker compose exec cerberus python -m cerberus.userctl reset-password --username OWNER_USERNAME

Active pentest is disabled

This installation was started with CERBERUS_ENABLE_ACTIVE_SCANS=false, so Nuclei, OWASP ZAP, and sqlmap are unavailable. Passive Surface, DNS & exposure, and Performance scans still work.

Docker Hub AIO: recreate only the launcher; named volumes and scan data are preserved.

docker rm -f cerberus-aio && docker run -d --name cerberus-aio --restart unless-stopped -p 8099:8099 -v /var/run/docker.sock:/var/run/docker.sock -v cerberus-aio-config:/config -e CERBERUS_AIO_CONFIG_VOLUME=cerberus-aio-config -e CERBERUS_ENABLE_ACTIVE_SCANS=true romanvaxman/cerberus-aio:0.2.1

For a standard Compose install, set CERBERUS_ENABLE_ACTIVE_SCANS=true in .env, then run docker compose up -d.
